# ADR-004: 重排信号权重封顶，禁止独断最终排序

## Status: Accepted (2026-09-24)

## Background

混合检索中接入重排器后，若把重排顺序直接当作最终排序，
一个在查询语言上力不从心的重排器会无人制衡地压掉正确答案。
实测同类系统中文查询 top-1 命中率可从 11/12 跌至 5/12。

## Decision

重排分与归一化 RRF 分线性混合：

```
final = (1 - w) * rrf_norm + w * rerank_score,  w <= 0.5（代码内强制钳制）
```

检索主信号（RRF 融合分）始终占至少一半权重；重排只作微调。
默认 w=0.3，环境变量可调，代码钳制上限 0.5。

## Consequences

- 正面：弱重排器最坏情况下也只能轻微扰动排序，不会压掉强检索结果
- 负面：强重排器的提升空间同样被限制
- 缓解：未来接入跨编码器重排模型后，经评估端点验证再上调权重
