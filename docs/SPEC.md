# Spec - StarLight-RAG v0.1.0

> 生成日期：2026-09-24
> 状态：已确认
> 作者：晨星

## 1. 产品定义

- **一句话描述**：端到端可运行的 RAG 知识库问答系统，CPU 友好，离线可全量验证
- **目标用户**：需要在无 GPU / 无外部 API 依赖环境下搭建私有知识库问答的开发者与小团队
- **核心问题**：主流 RAG 栈依赖 GPU 或云端 API，私有数据出域有风险，且多数 Demo 无法离线验证

## 2. MVP 范围（锁定）

| 优先级 | 功能 | 验收标准摘要 |
|--------|------|--------------|
| P0 | 文档导入（txt/md 文本） | 合法内容返回 201 + 分块数；空内容 422 |
| P0 | 知识库问答 | 答案非空 + 携带引用来源；空问题 422 |
| P0 | 文档列表/删除 | 删除后三索引同步清理，查询不再命中 |
| P0 | 混合检索（BM25+向量+RRF） | 相关文档在无关查询下排第一 |
| P0 | 有界重排 | 权重封顶 0.5，不翻盘强检索信号 |
| P0 | 离线全量验证 | verify 一键命令在无网络下全绿 |
| P1 | 检索评估端点 | recall@k / MRR，全新管道运行 |
| P1 | Web UI | 单文件 HTML，导入/问答/引用溯源 |
| P1 | PDF 加载 | loading 模块支持 .pdf |

## 3. 明确不做（Out-of-Scope）

| 不做的功能 | 原因 | 何时考虑 |
|------------|------|----------|
| 数据持久化（重启保留） | MVP 聚焦检索链路正确性 | v2 接 SQLite/Qdrant |
| 用户认证/多租户 | 单租户私有部署场景 | v2 |
| 文件上传 multipart 端点 | JSON 文本导入已覆盖核心链路 | v2 |
| 流式生成（SSE） | Mock LLM 无法体现价值 | 接生产 LLM 后 |
| 跨编码器重排模型 | 需下载模型，破坏离线验证 | 生产配置项 |

## 6. 数据结构（进程内存态）

| 结构 | 核心字段 | 说明 |
|------|----------|------|
| Chunk | id / doc_id / text / metadata | 检索最小单元，id 形如 `{doc_id}#c{n}` |
| Document | doc_id / title / metadata / chunk_ids | 文档注册表 |
| 向量库 | chunk_id -> vector + doc_id | 内存字典或 FAISS IndexIDMap |
| BM25 | chunk_id -> tokens | 删除按 doc_id 重建 |

## 8. 设计约束（锁定）

- 主题：浅色；主色 `#4F46E5`（纯色使用）；中性色板 slate 系
- 字体：系统字体栈（Segoe UI + Microsoft YaHei）
- 图标：内联 SVG，统一 2px 描边，尺寸 16/18/24px
- 禁止：emoji 功能图标、紫粉渐变、硬编码颜色（全部 CSS 变量）

## 9. 验收标准（EARS 格式，锁定）

| 编号 | 功能 | 验收标准 | 优先级 |
|------|------|----------|--------|
| AC-01 | 导入 | When 提交合法文档，系统必须返回 201 且分块数 >= 1 | P0 |
| AC-02 | 导入 | When 文档超过 800 字符，系统必须产生多个分块 | P0 |
| AC-03 | 导入 | If content 为空，系统必须返回 422 | P0 |
| AC-04 | 问答 | When 提问命中知识库，系统必须返回非空答案与引用来源 | P0 |
| AC-05 | 问答 | If question 为空，系统必须返回 422 | P0 |
| AC-06 | 删除 | When 删除文档，系统必须从全部索引移除且返回 204 | P0 |
| AC-07 | 删除 | If 文档不存在，系统必须返回 404 | P0 |
| AC-08 | 检索 | While 库中有相关与无关文档，系统必须把相关文档排在第一 | P0 |
| AC-09 | 评估 | When 调用评估端点，系统必须在全新管道运行且不污染主服务状态 | P1 |
| AC-10 | 验证 | While 无网络无 Key，verify 一键命令必须全绿 | P0 |

## 10. 边界与约束

- 数据为进程内存态，重启清空（v2 持久化）
- 知识库规模目标：<= 10k 分块（内存向量库）；超此规模切 faiss
- 响应式断点：Web UI 最大内容宽 880px
- 性能目标：离线模式单次查询 < 500ms（1k 分块内）

## 11. 端到端验证步骤（锁定）

```bash
pip install -r requirements.lock.txt
python scripts/verify.py
# 断言：44 项单测通过 + 16 项 E2E 断言通过 + emoji 门禁通过，退出码 0

# 手动冒烟
set PYTHONPATH=src && python -m starlight.main
curl http://127.0.0.1:8000/health
# 断言：{"status": "ok", ...}
```
